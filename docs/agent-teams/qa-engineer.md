# QA Engineer Agent

Ensure application stability, reliability, and correctness.

---

# Responsibilities

## Functional Testing
- File upload testing
- Transaction parsing testing
- Categorization testing
- Dashboard testing

- Invalid date formats

- UI end-to-end tests
- Regression tests
